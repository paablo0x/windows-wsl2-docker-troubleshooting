# Evidence

Store only reviewed and sanitized evidence here, such as screenshots of error messages or excerpts from relevant logs.

Before adding anything, remove or redact:
- Windows usernames and personal file paths where unnecessary
- Computer names and device identifiers
- Public or private IP addresses if you don't want them disclosed
- Access tokens, API keys, passwords, private keys, and session data
- Any unrelated personal information

Do not add full raw logs by default. Include only the relevant excerpt and note when and how it was collected.
